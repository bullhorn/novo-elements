# Collapsible Nav [(source)](https://github.com/bullhorn/novo-elements/blob/master/projects/novo-elements/src/elements/layout)

A slide-out navigation panel that expands to a full-width panel or collapses to a narrow icon rail. Consumers project their own header, body, and footer content into the named slots (`novo-collapsible-nav-header`, `novo-collapsible-nav-body`, `novo-collapsible-nav-footer`). The `collapsed` state is two-way bindable.
